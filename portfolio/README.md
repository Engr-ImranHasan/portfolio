# Imran Hasan — Portfolioএকটা সম্পূর্ণ static, single-page portfolio। কোনো build সার্ভার বা database লাগবে না —শুধু ফাইলগুলো GitHub-এ push করলেই চলবে।\---## ১. আপনার ফাইলগুলো যেখানে রাখবেনফোল্ডারগুলো আগে থেকেই বানানো আছে, শুধু ফাইল **ঠিক এই নামে** ভিতরে দিন:|আপনার ফাইল|কোথায় রাখবেন||-|-||`imran.jpg` (আপনার ছবি)|`assets/img/profile/imran.jpg`||`Imran-Hasan-CV.pdf`|`assets/cv/Imran-Hasan-CV.pdf`||`p1.pdf` … `p7.pdf`|`assets/img/projects/p1.pdf` … `p7.pdf`||`memory-1.jpg` … `memory-16.jpg`|`assets/img/memories/memory-1.jpg` …||শেয়ার থাম্বনেইল (১২০০×৬৩০ px, ঐচ্ছিক)|`assets/img/og/og-image.jpg`|> ছবি বা PDF না থাকলে পেজ ভাঙবে না — নিজের থেকেই একটা blueprint-style placeholder দেখাবে।**ছবির সাইজ টিপস:** প্রোফাইল ছবি 680×920 px, memory ছবি 1200×750 px রাখলে সবচেয়ে ভালো দেখাবে।সম্ভব হলে [squoosh.app](https://squoosh.app) দিয়ে compress করে নিন — পেজ দ্রুত load হবে।\---## ২. যা যা এডিট করতে হবে (মোট ৪ জায়গা)### (ক) প্রজেক্টের নাম ও বিবরণ`assets/js/main.js` খুলে একদম উপরে `PROJECTS` লেখা ব্লকটা পাবেন। ৭টা এন্ট্রি আছে, প্রতিটাতে:```js{ file: 'p1.pdf', cat: 'Structural Design', accent: 'blue',  title: 'G+15 Residential Tower — Full Structural Design',  desc: '…বর্ণনা…',  tags: \\\\\\\['ETABS', 'CSI SAFE', 'BNBC 2020'] },```> এখন যে নাম/বর্ণনা বসানো আছে সেগুলো আপনার CV ও research থেকে অনুমান করে লেখা —> আপনার আসল প্রজেক্টের নাম দিয়ে বদলে দিন।### (খ) আপনার GitHub Pages URLএই ৩টা ফাইলে `https://engr-imranhasan.github.io/portfolio/` খুঁজে নিজের URL বসান:`index.html` (canonical + og:url + twitter), `robots.txt`, `sitemap.xml`### (গ) Formspree (contact form)1. [formspree.io](https://formspree.io) → ফ্রি অ্যাকাউন্ট খুলুন (imran.cee23@gmail.com দিয়ে)2. **New Form** → একটা form id পাবেন, দেখতে এমন: `xwpekqjr`3. `index.html`-এ `https://formspree.io/f/YOUR\\\\\\\_FORM\\\\\\\_ID` এর `YOUR\\\\\\\_FORM\\\\\\\_ID` বদলান> এটা না করলেও সাইট চলবে — form-এ submit করলে "Formspree is not connected yet" লেখা দেখাবে।### (ঘ) সার্টিফিকেট`main.js`-এর `CERTS` array-তে আপনার CV-এর **PROFESSIONAL DEVELOPMENT \& TRAINING** অংশের১৬টা কোর্সই আছে, CV-এর ক্রম অনুযায়ী (metrics-এও 16+)। নতুন কোর্স যোগ করতে চাইলেarray-তে একটা লাইন বাড়িয়ে দিন, আর `index.html`-এর `data-count="16"` বদলে দিন —কার্ডের `01/16` কাউন্টারটাও তখন আপডেট করতে হবে।\---## ৩. লোকালি দেখা```bashcd portfoliopython3 -m http.server 8000# ব্রাউজারে: http://localhost:8000```\---## ৪. GitHub Pages-এ পাবলিশ```bashcd portfoliogit initgit add -Agit commit -m "Portfolio"git branch -M maingit remote add origin https://github.com/<আপনার-username>/portfolio.gitgit push -u origin main```তারপর GitHub repo → **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**।কয়েক মিনিট পরে সাইট লাইভ হবে: `https://<username>.github.io/portfolio/`> \\\\\\\*\\\\\\\*গুরুত্বপূর্ণ:\\\\\\\*\\\\\\\* repo-র নাম `portfolio` না হলে, সব জায়গায় URL-টা সেই অনুযায়ী বদলাতে হবে।\---## ৫. Tailwind CSS রি-বিল্ড (শুধু ডিজাইন বদলালে)সাইটে Tailwind CDN নেই — CSS আগে থেকে build করা (`assets/css/styles.css`)।কোনো নতুন Tailwind class যোগ করলে আবার build করতে হবে:```bashnpm install                 # একবারইnpx tailwindcss -i ./src/input.css -o ./assets/css/styles.css --minify```সাধারণ কনটেন্ট/টেক্সট বদলালে build লাগবে না।\---## ৬. ফোল্ডার স্ট্রাকচার```portfolio/├── index.html                  পুরো পেজ├── favicon.svg├── robots.txt  sitemap.xml├── tailwind.config.js├── src/input.css               CSS সোর্স (এডিট করলে rebuild)├── test-render.js              রেন্ডার টেস্ট├── check-assets.js             ফাইল-লিংক টেস্ট└── assets/    ├── css/styles.css          build করা CSS    ├── js/main.js              কনটেন্ট + সব ইন্টারঅ্যাকশন    ├── js/truss-bg.js          hero background animation    ├── img/icons.svg           আইকন sprite    ├── img/profile/            imran.jpg    ├── img/projects/           p1.pdf … p7.pdf    ├── img/memories/           memory-1.jpg … memory-16.jpg    ├── img/og/                 og-image.jpg    └── cv/                     Imran-Hasan-CV.pdf```\---## ৭. টেস্ট চালানো```bashnpm installnode test-render.js     # পেজ সত্যিই রেন্ডার হচ্ছে কিনা (jsdom)node check-assets.js    # সব ফাইল-লিংক ঠিক আছে কিনা```\---## Background animation কীভাবে কাজ করে* **Layer B** (পুরো পেজ): blueprint dot-grid খুব ধীরে সরে + একটা হালকা scan-line — pure CSS* **Layer A** (শুধু hero): canvas-এ structural truss-এর মতো node + member network,mouse-এর কাছে গেলে লাইনগুলো উজ্জ্বল হয়* hero স্ক্রল করে চোখের আড়ালে গেলে canvas **থেমে যায়** (CPU বাঁচে), ফিরে এলে আবার চলে* মোবাইলে (<768px) এবং OS-এ *Reduce motion* চালু থাকলে পুরোপুরি বন্ধ থাকে
